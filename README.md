# Certificate & Badge Generation Automation

An n8n-based workflow developed during my internship to automate the generation of course-completion certificates and digital badges.

## 📌 Project Overview

This project automates the process of generating certificates and badges based on course completion data.

The workflow uses n8n to connect different services, process the required data, and automate the generation process, reducing repetitive manual work.

## ⚙️ Technologies Used

- n8n
- Workflow Automation
- Google Sheets
- API Integration
- AI / LLM
- Git & GitHub
